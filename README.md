A [make.fun](https://make.fun) bounty entry: the funniest one-line excuse a
robot vacuum gives for missing a spot, in 200 characters or fewer.

`main.py` (Python standard library only) writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt`:

> I circled that spot three times on 4% battery, ran a full diagnostic, and concluded the crumbs were union reps. I never cross a picket line.

Run it with:

```sh
python3 main.py
```
